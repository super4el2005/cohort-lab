# Когорта

Демонстрационный реестр на Node.js 24 и SQLite. Сервер отдаёт JSON API и интерфейс на HTML, CSS и JavaScript. При первом запуске база получает 100 синтетических карточек.

| Роль | Возможности |
| --- | --- |
| Администратор | Реестр с полным CRUD, аналитика и список аккаунтов |
| Врач | Создание, просмотр, изменение и удаление карточек |
| Исследователь | Просмотр, фильтры по когорте, сравнение групп по парным измерениям, полнота наблюдений и CSV выборки |

Открытая регистрация выдаёт роль исследователя. Стартовые логины — `admin`, `doctor` и `researcher`. Пароли устанавливаются через окружение при первичной инициализации базы.

## Локальный запуск

```sh
export ADMIN_PASSWORD="$(openssl rand -hex 15)"
export DOCTOR_PASSWORD="$(openssl rand -hex 15)"
export RESEARCHER_PASSWORD="$(openssl rand -hex 15)"
npm start
```

Откройте http://localhost:3000. Стандартный путь к базе — `data/cohort.sqlite`. Для сервера с постоянным томом укажите `DB_PATH` внутри этого тома. Для HTTPS выставьте `NODE_ENV=production`. Точка проверки состояния — `GET /api/health`.

В демоверсии используйте только синтетические данные. SQLite на бесплатном Render хранится на временном диске и может сбрасываться при перезапуске или повторном развёртывании. Пересозданная база снова получает исходные карточки и три аккаунта из переменных окружения.
